# Bibliography

Real, verifiable primary sources for the neuro-design reference files — 536 references. Each key is referenced from a `**Cite:**` line in a reference file. The bibliography is organized in tiers: six **core lenses**, twenty **cross-domain sectors** (adjacent fields whose findings transfer to interface design), and successive **deepening passes** that add further principles, effect sizes, meta-analyses, and boundary/replication conditions. Sources are primary where a primary source exists and resolves; a few canonical practitioner/standards sources (Nielsen Norman Group, Apple/Google guidelines, W3C) are cited where they are the authoritative reference. Every link was verified to resolve during research (via CrossRef/OpenAlex/PubMed metadata and publisher redirects). A handful of works are cited under two keys in different files (the same underlying source). Key reconciliation is 1:1 — every `**Cite:**` key used across the reference files is defined here, and vice-versa.

A few widely-taught claims are deliberately **not** given a primary citation and are flagged in-file as "(widely taught; primary source not verified)" — notably the **Z-pattern / Gutenberg diagram** and **trichromacy** as historical background (Young 1802; Helmholtz 1852) in the core files, plus a small number of pre-DOI/foundational works elsewhere (each additionally backed by a DOI-verified modern source in the same entry).
